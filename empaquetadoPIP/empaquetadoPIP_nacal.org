* makefile

# +BEGIN_SRC  makefile :noweb no-export :results silent :exports none :tangle makefile

#+BEGIN_SRC  makefile :results silent :tangle makefile

############################ -*- Mode: Makefile -*- ###########################
DIRECTORIO_NACAL = $(abspath $(CURDIR)/..)

name = nacal

nacal:
	rm -r -f $(HOME)/$(name)
	mkdir -p $(HOME)/$(name)
	mkdir -p $(HOME)/$(name)/$(name)/
	cp $(DIRECTORIO_NACAL)/nacal/nacal.py $(HOME)/$(name)/$(name)/nacal.py
	cp $(DIRECTORIO_NACAL)/nacal/__init__.py $(HOME)/$(name)/$(name)/__init__.py
	cp $(DIRECTORIO_NACAL)/LICENSE $(HOME)/$(name)/
	pandoc --from=org --to=gfm $(DIRECTORIO_NACAL)/README.org > $(HOME)/$(name)/README.md
	cp pyproject.toml $(HOME)/$(name)/
	cd $(HOME)/$(name)/; python3 -m build
	cd $(HOME)/$(name)/; twine check dist/*

upload: nacal
	cd $(HOME)/$(name)/; twine upload --repository nacal dist/*

#+END_SRC


#+name: make
#+BEGIN_SRC bash :results silent :exports none
make nacal
#+END_SRC

#+name: makeUpload
#+BEGIN_SRC bash :results silent :exports none
make upload
#+END_SRC


* Instalación local de la versión de trabajo

Para instalar en el ordenador la versión del repositorio (sin subirla a PyPI):

1. Situar el repositorio en la rama que se quiere instalar (normalmente =master=). Si no se quiere
   cambiar de rama, se puede extraer con =git archive master= a una carpeta temporal y copiar en
   ella los ficheros =makefile= y =pyproject.toml= de este directorio (se generan a partir de este
   documento y no están en git).
2. Construir el paquete: =make -C empaquetadoPIP nacal= (borra y vuelve a crear =~/nacal=).
3. Instalarlo. En Debian 12 =pip install --user= se niega a instalar fuera de un entorno virtual
   (PEP 668), así que hay que indicarlo expresamente:

#+BEGIN_EXAMPLE
pip install --user --no-deps --break-system-packages ~/nacal/dist/nacal-X.Y.Z-py3-none-any.whl
#+END_EXAMPLE

La opción =--no-deps= evita que =pip= actualice =sympy= e =ipython=, que ya están instalados con
los paquetes del sistema.

* pyproject.toml

Los metadatos del paquete se indican en el fichero =pyproject.toml= (que sustituye al antiguo
=setup.py=). El número de versión se lee del fichero =nacal/__init__.py=. Para construir el paquete
es necesario el módulo =build= (en Debian: =sudo apt install python3-build python3-venv=).

La versión de =setuptools= se limita a las anteriores a la 69 (y la licencia se indica con el
formato antiguo) porque las versiones recientes generan metadatos en un formato (2.4) que el
=twine= 4.0.2 de Debian 12 no sabe leer, por lo que no podría subir el paquete a PyPI. Cuando se
disponga de =twine= >= 6.1 se podrá quitar el límite e indicar la licencia con
~license = "GPL-3.0-only"~ (quitando el clasificador de la licencia).

- [[https://packaging.python.org/en/latest/guides/writing-pyproject-toml/]]

#+BEGIN_SRC toml :tangle pyproject.toml
[build-system]
requires = ["setuptools>=61,<69"]
build-backend = "setuptools.build_meta"

[project]
name = "nacal"
dynamic = ["version"]
description = "Notacion Asociativa para un curso de Algebra Lineal (NAcAL)"
readme = "README.md"
authors = [{name = "Marcos Bujosa", email = "mbujosab@ucm.es"}]
license = {text = "GPLv3"}
requires-python = ">=3.6"
dependencies = ["sympy>=1.1.0", "ipython"]
keywords = ["nacal"]
classifiers = [

    "Operating System :: OS Independent",
    "Intended Audience :: Education",
    "Framework :: Jupyter",
    "Environment :: Console",

    "Topic :: Scientific/Engineering :: Mathematics",
    "Development Status :: 3 - Alpha",
]

[project.urls]
Homepage = "https://mbujosab.github.io/nacallib/"

[tool.setuptools]
packages = ["nacal"]

[tool.setuptools.dynamic]
version = {attr = "nacal.__version__"}
